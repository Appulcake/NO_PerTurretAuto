Long pressing "Toggle Turret Control" keybind toggles blacklist state of a currently selected weapon (if it has actual turrets that can auto fire when not under pilot manual control).
Doing this while holding "Axis Modifier" clears the entire blacklist.
Optionally, a HUD indicator (on by default) shows if there's any such turret weapons that are currently blacklisted/disabled from auto firing.
This indicator is anchored to the right of the throttle gauge and its X and Y offset and font size can be adjusted, or the indicator can be altogether disabled in `BepInEx/config/NO_PerTurretAuto.cfg` (or via BepInEx Configuration Manager's F1 menu).
